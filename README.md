# NextJs-Portfolio

A modern, interactive personal portfolio website built with Next.js, React, Tailwind CSS, and Framer Motion.

## 🚀 Features

- **Cyber-Themed Interactive UI**: Futuristic visuals with cyber animations, floating code backgrounds, and neon accents.
- **Multiple Color Themes**: Real-time theme switcher featuring Dark, Cyberpunk, Midnight, Matrix, and Ocean palettes.
- **Interactive Code Showcase**: Interactive code editor tabs highlighting TypeScript, Python, and JavaScript snippets.
- **Dynamic Skills & Services**: Categorized technical skills with smooth animated filtering.
- **Project Gallery**: Categorized portfolio showcases with tags and links.
- **Interactive Resume Generator**: Client-side PDF resume generation powered by `@react-pdf/renderer`.
- **Fully Responsive**: Optimized for desktop, tablet, and mobile screens.

## 🛠️ Tech Stack

- **Framework**: [Next.js](https://nextjs.org/) (App Router)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **PDF Generation**: [@react-pdf/renderer](https://react-pdf.org/)

## 🏁 Getting Started

First, install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to view the portfolio.

## 📦 Production Build

```bash
npm run build
npm run start
```
